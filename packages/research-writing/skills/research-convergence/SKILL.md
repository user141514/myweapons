# Research Convergence / 科研收束

以用户目标为锚，以能改变决策的证据推进。先建立最小 Model，再写 Claim、Invariant、Counterexample，最后形成实验规则；不是先写一个新方法名字，再寻找支持它的故事。

如果当前行为主要是在管理论文候选组合、诊断低产出、从历史结果挖 paper-shaped 机会、决定 CARD/GAP/PILOT/FULL 生命周期，而不是选择科学假设本身，则转用 `research-factory`；不要因为同属科研就同时固定加载全部技能。

## 1. 恢复并固定任务

核对最新用户原文、修订、真实主机/目录/源码/结果和已有决策账本。摘要、旧 skill、子代理意见和旧完成状态都是证据，不是新授权。复用有效资产，不从头扫一遍，也不自动续跑失效计划。

先写一张短卡：**目标；当前状态；证据；最小模型；边界；首个真正未知；本轮交付**。区分研究母题、工作问题、方法假设、已确认贡献。项目名称、模型、阈值和已关闭变体放在项目卡，不写成此技能的通用常量。

## 2. 收束循环

| 阶段 | 所需产物与前进条件 |
|---|---|
| S0 任务与基线 | 一个主任务、输入/输出/条件、命名直接基线；论文、代码、数据、权重和本地可运行性分别登记 |
| S1 缺口 | 原论文/源码线索或理论预测与本地复现分开；排除运行错误、数据泄漏、筛选和预算混淆 |
| S2 竞争假设 | 默认至多三个候选，每个写观察→判断→若错会出现什么；明确干预、最近先例和廉价替代 |
| S3 判别实验 | 选择最上游、最低成本且能改变排序的实验；锁定对照、预算、分母、指标、实现验收和停止条件 |
| S4 方法与消融 | 原基线、最强廉价替代、最近方法及单因素干预；质量、覆盖和总成本共同判断 |
| S5 独立确认 | 分开探索与确认数据/种子，报告不确定性、负面边界、完整复现材料；只主张证据支持的范围 |

它是证据顺序，不是要求一次填满所有阶段的仪式。问题已明确且下一未知只能由真实模型行为回答时，停止泛搜，执行有界实验；必要的小型学习实验可以是判别实验。未知数值标记未定，先测方差/成本，不借用别的项目阈值。

## 3. 两条审查线

**有效性**：同一任务、数据划分及可比总预算下，是否改善真实结果，且不靠筛选牺牲覆盖？

**新意**：分别搜索问题分解、局部组件、组合/接口语义；查最近直接论文、官方代码及异名同义方法。需要时追术语来源，但只追到能改变决策的深度。有限检索无命中不是首次证明。

不要求新架构、新物理变量或无法串行分解才算方法研究；过程、目标、表示、训练、条件和推断均可提出假设。简单操作若能精确消除所声称问题，先作为基线；仅能想象一个串行流程，不等于已证明它同预算有效。

## 4. 决策与反漂移

每轮明确选择：**实现/数据无效需修复；有效但信息不足；候选无净优势；有效但新意不足；值得独立确认**。

反例仅否定实际覆盖的条件/实现。候选失败导向证据驱动的方法/架构修改或停止；不靠换任务、换评价、事后阈值或叙事保路线。不得自动转为 benchmark、机制、资源或负结果论文；用户明确改变研究目标时，另立任务并保留旧结果。失败次数、文档数量和排障时长不是算法贡献。

新应用概念必须接回“任务缺口→具体方法干预→同任务验收”；接不回就停，不让前置生化或工具项目替代主线。默认一个活跃实验方向，其他候选只排队。

## 5. 实验与恢复不变量

保留所有尝试分母，分开原始输出、统一修复后输出和筛选后输出；登记版本/权重/配置/数据/种子/命令/退出状态/结果哈希。网络调用次数相同不代表总成本相同；计入引导、后处理、失败重试、训练及实测资源。

长任务先持久化任务身份与 checkpoint，超时后先读权威状态和结果，已完成则收取而非重跑。进程成功不等于科学通过，心跳不等于主对话恢复。遵守当前可用工具契约及用户并发/发送间隔，未验证的 Sidecar、mem 或 watchdog 能力如实记录；工具故障不得无限扩展为主任务。只在授权和工具支持范围执行，不承诺后台交付。

## 6. 汇报与工作记录

每次用短段落或一张表交付：**当前问题→事实/证据→判断→尚不能声称什么→下一项会改变判断的动作**。写明预测与实际差异，更新一条可迁移识别规则。保留用户原文、当前计划和旧计划失效关系；有界子任务完成不等于整个研究完成。

开始新项目或预注册实验时读 [field-guide.md](references/field-guide.md) 的记录配方与完整示例；部署或修改本技能时读 [acceptance-scenarios.md](references/acceptance-scenarios.md)。本技能提供执行方法，不提供本地工具命令的虚构兼容层。
