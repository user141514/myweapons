# journal-writing v1 freeze

Date: 2026-09-21
Status: structural v1 frozen

## Acceptance result

v1 is accepted as the first independently trained journal-writing structural Skill.

It is independent from `top-conference-paper-writing` and was derived from real published papers through repeated mimic -> transfer test -> counterexample -> mutation -> locked forward test cycles.

## Stable universal controllers

- S1 Dependency-first composition
- S2 Premise trust before downstream consumption
- S3 Abstract as a minimum claim-authorization cutset
- S4 Opening as bounded re-anchor plus missing prerequisite debt
- S5 Results paragraph as one decision-consumable state update
- S6 Main figures optimize scarce visible decision value
- S7 Closing claims maximize authorized semantic strength
- S8 Title as the nearest distinctive authorized claim handle

These are stored in `../SKILL.md` and are the only universal rules promoted in v1.

## Stable claim-type adapters

- A1 Resource
- A2 Generalist method
- A3 Unified computational platform
- A4 Engineered system
- A5 Molecular causal mechanism
- A6 Clinical intervention

Authoritative compact routing/reference: `ADAPTERS.md`.

## Evidence that the model became generative rather than only retrospective

Key locked tests:

- Round 010: forward figure-order prediction on the human pangenome failed; failure created the premise-trust / artifact-stack correction instead of being explained away.
- Round 011: revised model exactly predicted all six main-figure positions in the Cell deep-learning antibiotic-discovery paper.
- Rounds 013–014: abstract information selection was predicted before reveal in engineered-system and randomized-clinical regimes; the clinical test correctly predicted retention of the later null primary result.
- Rounds 015–017: Introduction predictions forced two model revisions and then matched the clinical AVATAR2 opening after the bounded-re-anchor rule was formed.
- Round 018: Results prediction got the macro path right but granularity wrong; this refined the paragraph unit to one decision-consumable state update.
- Round 019: main-figure selection failed and exposed visual explanatory efficiency/actionable leverage as missing variables.
- Round 020: revised figure-allocation model exactly predicted all 15 main-versus-Extended packet placements and the six-main-figure order in RFdiffusion.
- Round 021: Discussion claim-boundary prediction survived AVATAR2 and refined calibration from hedge-counting to semantic authorization.
- Round 022: first title prediction missed by over-weighting the value proposition.
- Round 023: revised title model correctly predicted the identity-bearing structure of a different Nature paper.

## v1 invariants

1. No journal-wide fixed outline, figure quota, paragraph formula or numeric quality score.
2. Journal family is not the primary router; claim object and evidence regime are upstream.
3. Counterexamples may delete or narrow rules.
4. Evidence that changes the legal claim cannot be compressed away for narrative convenience.
5. A new premise must earn enough trust before downstream claims spend it.
6. Visible prose/figures are projections of the proof model, not the proof model itself.

## Intentionally untrained / not frozen in v1

These are explicit boundaries, not hidden claims of competence:

- detailed Methods / STAR Methods organization and reproducibility microstructure;
- figure-caption and Extended-Data-caption microstyle;
- sentence-level journal prose rhythm, lexical density and transition wording beyond the structural controllers;
- reference/citation placement conventions;
- Supplementary Methods / Supplementary Note architecture;
- journal-specific submission formatting and house-style constraints;
- Reviews, Perspectives, News & Views and other non-original-research article types;
- cover letters, reviewer rebuttals and editorial correspondence.

These surfaces should be trained in later versions only when a real task requires them. Do not extend v1 merely for completeness.

## Release rule

Use v1 now for real manuscript drafting/restructuring/review.

When reality exposes a failure:
1. identify whether S1–S8, an adapter, or an untrained surface caused it;
2. reproduce the mismatch against a real published comparator;
3. mutate the smallest responsible rule;
4. lock a forward test before promotion.

Do not restart training from zero.
