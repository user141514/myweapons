# 使用说明

用途：Nature / Science / Cell 及高水平长篇期刊的结构、证据组织和 asset-to-prose 写作。

触发：明确面向高水平 journal family，或需要长篇 journal-style manuscript。

依赖：SKILL.md 是结构核心；training/ADAPTERS.md 是 claim-type 路由；training/EXECUTION.md 是资产到 prose 执行层。

最小使用：central claim -> unresolved transitions -> evidence dependency/proof graph，再让 section、paragraph、figure 成为 proof graph 的投影。
