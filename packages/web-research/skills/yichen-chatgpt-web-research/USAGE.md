# 使用说明

用途：通过用户已经登录的官方 ChatGPT 网页账户进行产品、市场、竞品或 second-opinion 研究。

触发：用户明确要求 ChatGPT 官网/网页版/Pro 路线，或希望复用网页账户而非 API。

浏览器依赖：优先外部 `chrome:control-chrome`；不可用时可回退到 Computer Use。该浏览器控制插件不是本仓原创资产，因此只声明依赖、不复制其源码。

最小使用：锁定正确 Chrome profile 与真实 ChatGPT tab → 验证账户/模型 → 从页面发送自包含研究 prompt → 等待可见完成 → 提取并保存 Markdown → 核对 completion marker。
